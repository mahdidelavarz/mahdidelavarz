I build data-heavy business software. Since 2024 I've been building a React + TypeScript ERP of about 80 pages for a pump and turbine manufacturer (PETCO), and I care about architecture that keeps large frontends small, fast and consistent.

## What I've built at work

- **PageShell**: a factory-based page system with plugins (file upload, digital signature, reporting) and nested pages. Cut code size by 60% and now powers 57 of the ERP's 80 pages.
- **Shared data tables**: client and server versions with server-side paging, sorting and filtering.
- **Multi-tab workspace** and an **approval workflow** used across the ERP.
